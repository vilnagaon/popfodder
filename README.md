# PopFodder

An iOS squad-tactics game. Tap soldiers, send them across a battlefield, try not to spend the people you like.

**License: GPL-3.0.** See `LICENSE`. This is original work in the spirit of Sensible Software's Cannon Fodder — original name, original art, original maps. It is not a reskin and does not include Cannon Fodder or OpenFodder assets.

## Build

```bash
brew install xcodegen   # if needed
xcodegen generate
open PopFodder.xcodeproj
```

- Team: `GZYFXW9AWA`
- Bundle ID: `be.gampa.popfodder`
- iOS 17+, landscape

Do not edit the `.xcodeproj` by hand. Change `project.yml`, then `xcodegen generate`.
